## What this project is

Demian Video Editor Portfolio is a browser-hosted collection of video editing and motion design pieces. It surfaces work that leans on punchy cuts, motion graphics, effects, fluid transitions, and intentional audio.

Anyone scanning for social-first visuals—especially YouTube and TikTok—can use it as a quick map of style and craft. Mentions of After Effects and Premiere Pro workflows help frame how the showcased edits come together.

---

## What you will find

- Featured reels of energetic video edits
- Motion graphics and design-focused sequences
- Sample visual effects treatments
- Edits built around clean, smooth transitions
- Moments that call out sound design choices
- Pieces shaped for YouTube and TikTok delivery
- Examples of social media video production
- A fully browser-based viewing experience

## Getting a local copy

Clone the repo:

```bash
git clone https://github.com/cedricgreen7/demian-editor-portfolio-hub.git
cd REPO
```

Load `index.html` directly in a browser, or point any static file server at the project folder.

Python one-liner for a local server:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000/`.

## How to use it

1. Launch the site in a current desktop or mobile browser.
2. Move through the highlighted editing and motion design entries.
3. Study the motion graphics, VFX, transition, and audio examples on each piece.
4. Treat the collection as a reference when planning YouTube, TikTok, or other social cuts.
5. Change HTML and project media as needed, then refresh locally to confirm updates.

---

## Customizing the site

Everything is static HTML. Copy, layout, and look-and-feel live in the repo itself—there is no external config backend.

Practical edit path:

- Change wording and structure in the main HTML file.
- Swap or refresh media tied to each project block.
- Tune CSS for grid, color, type, and spacing.
- Revise outbound links and project blurbs where they no longer match.
- Check the result on your machine before you ship.

## FAQ

### Where can I open the live portfolio?

Use [View the Portfolio](https://cedricgreen7.github.io/demian-editor-portfolio-hub/), or open `index.html` after you clone or download the repo.

### How do I run it offline on my machine?

Get the repository, enter the project folder, and open `index.html`. For day-to-day edits, a local static server is often more reliable.

### Where does configuration live?

Markup, styles, and media in the repository define content and presentation. There is no separate settings service.

### How do I introduce or swap a project?

Edit that project’s HTML section and align the media files with the paths the page already expects.

### When do changes go live?

After updated site files are committed and deployed to whatever host serves the portfolio.

### Media files are missing—what next?

Confirm each asset is present, filenames and paths match the HTML, and reload via a local server instead of a broken direct file path.
